## 2026-11 蓝白 Dashboard 界面改版

本次改版仅调整前端展示层与导航状态反馈：

- 采用深海军蓝、主蓝、中蓝、浅蓝与白色的配色体系。
- 首页改为 Dashboard 布局，新增顶部快捷导航和三个快捷入口卡片。
- 左侧导航改为深蓝色导航栏，并保留所有原有功能入口。
- 优化统计卡片、面板、按钮、表单、学习计时器、图表和移动端布局。
- 更新 Service Worker 缓存版本，避免浏览器继续使用旧版 CSS/JS。

**未重写学习算法、计时逻辑、复习间隔、熟练度计算、错题处理、学习数据结构或 localStorage 键名。** 原有浏览器中的学习数据继续使用原存储键读取。
